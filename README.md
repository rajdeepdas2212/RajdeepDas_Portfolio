# Rajdeep Das - Professional Portfolio Website

A fast, responsive, and modern developer portfolio built with semantic HTML5, modern CSS3 (Custom Variables, Flexbox/Grid), and vanilla JavaScript.

## 🚀 Features
- **Dark Minimalist Aesthetic:** Optimized dark theme with glowing accents and smooth typography.
- **Responsive Layout:** Perfectly adapted for mobile phones, tablets, and widescreen displays.
- **Interactive Sections:**
  - Hero with status indicator and punchy title.
  - Interactive Developer Terminal Profile card.
  - Categorized Technical Skills Grid (Languages, Frameworks, Tools, Fundamentals).
  - Project Cards with tech stack tags and direct links.
  - Experience Timeline highlighting internship at Ardent Computech and academic background at BPPIMT.
  - Functional Contact Form with quick clipboard email copy button.
- **Clean Codebase:** Zero bulky frameworks or dependencies required.

## 📁 File Structure
- `index.html` - Semantic structure, accessibility attributes, and metadata.
- `style.css` - Custom styling, fluid typography, dark mode palette, and animations.
- `script.js` - Mobile drawer toggle, scroll-spy navigation, copy-to-clipboard, and form handling.

## 🛠️ How to Deploy to GitHub Pages
1. Extract the contents of this `.zip` file into your local GitHub repository folder (`Rajdeep-Das`).
2. Test locally by double-clicking `index.html` or opening with VS Code Live Server.
3. Commit and push the updated files:
   ```bash
   git add .
   git commit -m "Update portfolio with professional design and complete project sections"
   git push origin main
   ```
4. Your site will automatically update at `https://rajdeepdas2212.github.io/Rajdeep-Das/`.
